# Huawei Pura 80 (HED-LX9) 

Huawei Pura 80 features an OLED display with integrated eye comfort technologies.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  

Calibration/Settings optimized for visual comfort while maintaining natural color reproduction.

Official product page:  <https://consumer.huawei.com/ru/phones/pura80/>

## Specifications  

| Parameter           | Value                                       |
| ------------------- | ------------------------------------------- |
| Screen size         | 6.6" (6.58" standard-rectangle measurement) |
| Panel type          | LTPO OLED                                   |
| Aspect ratio        | ~20:9                                       |
| Resolution          | 2760 × 1256                                 |
| Pixel density       | 460 ppi                                     |
| Backlight           | Self-emissive (OLED)                        |
| Refresh rate        | 1–120 Hz (adaptive LTPO)                    |
| PWM dimming         | 1440 Hz high-frequency PWM                  |
| Touch sampling rate | Up to 300 Hz                                |
| Color depth         | 1.07 billion colors                         |
| Color gamut         | P3 wide color gamut                         |
| Contrast ratio      | Effectively infinite (OLED)                 |

### Color characteristics

## Daily use configuration   

The priority here is: **long-term visual comfort → readability → luminance control → natural and stable image reproduction → other parameters.**  

### Recommended display settings (eye comfort)

| Parameter                    | Value            |
| ---------------------------- | ---------------- |
| Brightness                   | Auto             |
| Dark mode                    | OFF — Light mode |
| Eye comfort / eye protection | OFF              |
| Flicker reduction            | OFF              |
| Font size                    | Default          |
| Font weight                  | Default          |
| Color mode                   | Normal           |
| Color temperature            | Default          |
| Smart resolution             | On               |
| Refresh rate                 | Dynamic          |
