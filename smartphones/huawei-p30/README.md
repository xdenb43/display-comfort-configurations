# Huawei P30 (ELE-L29) 

Huawei P30 features an OLED display with a wide DCI-P3 color gamut and integrated eye comfort features.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  
  
Settings optimized for visual comfort while maintaining natural color reproduction and maximum display clarity.  

Official product page:  <https://consumer.huawei.com/qa/phones/p302/>

## Specifications  

| Parameter           | Value                                 |
| ------------------- | ------------------------------------- |
| Screen size         | 6.1" (standard-rectangle measurement) |
| Panel type          | OLED                                  |
| Aspect ratio        | ~19.5:9                               |
| Resolution          | 2340 × 1080                           |
| Pixel density       | ~422 ppi                              |
| Backlight           | Self-emissive (OLED)                  |

## Daily use configuration   

The priority here is: **visual comfort → readability → luminance control → natural and stable image reproduction → other parameters.**  

### Recommended display settings (eye comfort)

| Parameter                    | Value            |
| ---------------------------- | ---------------- |
| Brightness                   | Auto             |
| Dark mode                    | OFF — Light mode |
| Eye comfort / eye protection | OFF              |
| Flicker reduction            | ON               |
| Font size                    | Default          |
| Font weight                  | +1 step          |
| Color mode                   | Normal           |
| Color temperature            | Cold             |
| Screen resolution            | High             |
