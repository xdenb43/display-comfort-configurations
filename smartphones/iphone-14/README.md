# Apple iPhone 14 (A2882 / MPVN3HN/A)

The iPhone 14 features a Super Retina XDR OLED display with a wide P3 color gamut and adaptive display features.

Although OLED displays provide excellent contrast, deep blacks and high image quality, their brightness modulation and high luminance may cause visual discomfort for some users during prolonged use.

Settings optimized for daily use and visual comfort while maintaining natural color reproduction, readability and display clarity.

Official product page: <https://support.apple.com/en-us/111872>

## Specifications  

| Parameter           | Value                                 |
| ------------------- | ------------------------------------- |
| Screen size         | 6.1" (standard-rectangle measurement) |
| Panel type          | OLED                                  |
| Aspect ratio        | ~19.5:9                               |
| Resolution          | 2532 × 1170                           |
| Pixel density       | ~460 ppi                              |
| Backlight           | Self-emissive (OLED)                  |
| Refresh rate        | 60 Hz                                 |
| PWM dimming         | Not officially specified by Apple     |
| Touch sampling rate | Not officially specified by Apple     |
| Color depth         | 16.7 million colors (8-bit)           |
| Color gamut         | Wide color gamut (P3)                 |
| Contrast ratio      | Effectively infinite (OLED)           |

## Daily use configuration  

The priority here is: **visual comfort → readability → controlled luminance → stable and natural display behavior → secondary parameters.**  

### Recommended display settings (eye comfort)

| Parameter   | Value              |
| ----------- | ------------------ |
| Appearance  | Light until sunset |
| Brightness  | Auto               |
| Text size   | Default            |
| Bold text   |                    |
| True tone   | ON                 |
| Night shift | ON — 22:00–07:00   |

### Accessibility — display & text size   

| Parameter                   | Value         |
| --------------------------- | ------------- |
| Bold text                   | OFF           |
| Larger text                 | OFF / Default |
| Button shapes               | OFF           |
| On/off labels               | OFF           |
| Reduce transparency         | OFF           |
| Increase contrast           | OFF           |
| Differentiate without color | OFF           |
| Prefer horizontal text      | OFF           |
| Smart invert                | OFF           |
| Classic invert              | OFF           |
| Color filters               | OFF           |
| Reduce white point          | OFF           |

### Accessibility — motion  

| Parameter                  | Value |
| -------------------------- | ----- |
| Reduce motion              | OFF   |
| Dim flashing lights        | ON    |
| Auto-play animated images  | OFF   |
| Auto-play video previews   | OFF   |
| Message effects            | ON    |
| Prefer non-blinking cursor | OFF   |
